# 🔥 FileForge

**Simple file converter with GUI - Convert images and videos in one click**

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

- 🖼️ Convert PNG ↔ JPG instantly
- 🎬 Convert MP4 to GIF (first 10 seconds)
- 🎨 Dark mode GUI for comfortable use
- ⚡ Fast and lightweight

## 🚀 Installation & Usage

### For Windows Users (Easiest Way)

Just **double-click** the `run.bat` file. It will automatically:

1. Install all required dependencies (Pillow, MoviePy)
2. Launch the FileForge app

> **Note:** Make sure Python is installed on your system first. Download from [python.org](https://python.org)

### For Mac/Linux Users (or Manual Installation)

Open terminal and run:

```bash
# Install dependencies
pip install -r requirements.txt

# Run the app
python main.py
